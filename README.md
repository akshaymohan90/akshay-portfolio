## 🚀 Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (Turbopack, App Router)
- **Library**: [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Animations**: [GSAP](https://gsap.com/) (ScrollTrigger, SplitText) & [Lenis](https://lenis.darkroom.engineering/) smooth scrolling
- **Styling**: SCSS / Bootstrap 5 / Dark & Light Themes
- **Deployment**: [Vercel](https://vercel.com/)

---

## 🛠️ Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/akshaymohan90/akshay-portfolio.git
   cd akshay-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
